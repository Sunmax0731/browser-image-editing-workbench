# v0.1.0-alpha.1 Closed Alpha

## 位置づけ

ブラウザ画像編集ワークベンチ のクローズドアルファ版です。画像を読み込み、レイヤー、選択範囲、切り抜き、リサイズ、回転、色調補正、フィルタ、ブラシ、消しゴム、テキスト、透過保持、履歴管理をブラウザ上で扱う。Photoshop的な基本操作を軽量なWebツールとして提供し、編集後のPNG、WebP、JPEGを書き出す。
